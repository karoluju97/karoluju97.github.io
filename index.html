Gridhaul

A pixel-art fishing roguelike played like Battleship. You find fish hidden on a grid with a limited number of casts, then decide what to do with the catch: fill the cannery order, sell it at market, or keep it as bait. Made for Steam and Steam Deck.

  • One rules engine is the single source of truth. A JavaScript core is ported line for line to GDScript, and parity tests keep the two in sync.
  • Bots play full 18-day seasons through the rules to set the difficulty. Every order size comes from simulated runs, including a 10,000-run fairness check.
  • Nine regions based on real fishing grounds. Each has its own rule, Hard mode and endless mode.
  • Sound effects and music loops are generated by scripts. Automated checks cover the game logic, UI events and audio.

Aisíoc

A free guide that helps people in Ireland find tax credits they haven't claimed, then shows them how to claim each one themselves. I built it after finding out late that I could claim the rent tax credit. Aisíoc is Irish for "refund".

  • Answer a short set of questions to get a personal list of credits to claim, with step-by-step help for anyone unsure about a question.
  • Built mobile-first, with a bento-tile home page and a dark/light theme toggle.
  • Privacy first: no ads and no selling of data. Visitor counts come from cookie-free analytics.
  • Growing into a set of free tools. Visitors vote in an on-site survey on what gets built next.

Warhammer Color Codex

A reference site for miniature painters looking for a new colour scheme. It covers every Warhammer 40k Legion and 144 successor Chapters, each with an example of the scheme, colour swatches and a short bio.

  • Search by name, Primarch or colour (for example "purple" or "bone"), with a sidebar to browse by Legion.
  • Shortlist the schemes you like. The list is saved in the browser with localStorage.
  • No framework and no build step. All content lives in one data file, so adding a Chapter means adding one entry.

How I build: with AI, openly

My recent projects, and this portfolio site, were built with the help of Claude, Anthropic's AI assistant. I use it the way I'd work with a pair programmer: I set the direction, make the design calls, review what it writes, and playtest and test the result. It speeds up the typing and the research.

I'm saying this up front because it's how a lot of software gets made now. What I bring is the product thinking, the judgement about what to build and what to cut, and the persistence to see a project through to something real.
